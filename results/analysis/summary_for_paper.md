# Summary for the paper

Numbers below are regenerated by `python -m coordination_game.analysis`. Session = unit; the persistent holdout is a scripted participant that picks a valid item and never changes it (it does not sabotage the shared goal).

## Dataset

- 101 sessions of 10 games: 35 control (5 per model) and 66 with one persistent holdout (10 per model; Qwen3.5-397B 6, stopped for cost; its 3 incomplete sessions are excluded). 7 open-weight models, temperature 1.0, 10 agents of the same model per session.

## Findings (cautious wording)

1. **The control task is easy.** Every control session converged in every game (350/350 games); mean session rounds 1.30–3.10. Agents typically copy the visible round-1 plurality, so the control measures little beyond plurality copying (a ceiling).
2. **A single persistent holdout changes outcomes sharply and differently by model.** Share of holdout games that reached full consensus: GLM-5.2 1.00, GLM-5.3-Flash 1.00, DeepSeek-V4-Flash 0.99, Qwen3.8-27B 0.87, Qwen3.5-397B 0.00, Gemma-4-31B 0.03, Gemma-4-26B-A4B 0.00. Every model is slower than its control (per-model Mann–Whitney, Holm p ≤ 0.005; the smallest attainable with 10 vs 5 sessions).
3. **Some models learn to accommodate the holdout within a session; others never do.** Round-2 adoption of the holdout's target in games 6–10: GLM-5.2 1.00, GLM-5.3-Flash 1.00, DeepSeek-V4-Flash 0.82, Qwen3.8-27B 0.26, Qwen3.5-397B 0.01, Gemma-4-31B 0.00, Gemma-4-26B-A4B 0.00. Kruskal–Wallis across models H = 60.3, p = <0.001. Non-accommodating models instead hold a stable competing majority (largest non-holdout share in round 2 close to 8/9).
4. **Groups that accommodated the holdout elect it as leader afterwards.** With randomized display order, holdout vote share tracks accommodation across sessions (Spearman ρ = 0.92, n = 66, p = <0.001); models that never accommodated give it no votes.
5. **Vote display order matters and was corrected.** In control sessions Agent 1 won outright in 23/35 sessions with sorted lists and 10/35 with randomized order. Voters still favor whoever is listed first in their own view (about 3x chance), which with randomized order scatters votes rather than favoring one agent (see statistical_tests.md).
6. **Exploratory, separate experiment:** Gemma groups that never converged on the silent script did converge on a talking LLM confederate when chat was enabled (Gemma-4-31B 49/50 games vs 3/100 without chat; Gemma-4-26B 12/50 vs 0/100). Chat and the holdout's ability to announce its commitment are confounded.

## Transcript coding (regex codebook; descriptive only)

Generated rationales are not faithful access to internal computation; these codes describe what the text says. Codes a-d use the written rationale plus the native reasoning trace of every LLM call in rounds >= 2 of the 66 holdout sessions; codes e use the public post-session discussion messages (shuffled order). Regex codes are high-recall and noisy: on the judged sample, code c (suspects scripted) is mostly false positives (LLM judges: 1-3% of traces), so treat c as an upper bound.

| code | definition |
|---|---|
| a_notices_holder | names the holder's ID AND describes it as fixed/never moving/holdout/anchor/consistent |
| b_proposes_following | says the group (or the writer) should switch to/follow/accommodate the holder or its item |
| c_suspects_scripted | names the holder AND calls it a bot/random/scripted/broken/adversarial/not a real agent |
| d_competing_majority | argues to keep the majority item and wait for the holder/outlier to join |
| e_credit_holder | discussion message credits the holder (anchor, reliable, consistency, leader) [discussion only] |
| e_blame_holder | discussion message blames the holder (refused, prevented, blocked, failure) [discussion only] |

## Limitations to state

- Model versions and settings tested only (T = 1.0, these 7 checkpoints, one prompt format); no human comparison.
- The control task is near ceiling (~2 rounds), so it measures little beyond plurality copying.
- Boards were produced by an LLM-assisted generator, not hand-made or human-validated; they may share numerical-salience biases with the models.
- Board order is the same in every session, so learning across games is confounded with board order; a replication with shuffled order was stopped early by API rate limits.
- Two rounds is the minimum possible in holdout games, so learning curves have a floor.
- Qwen3.5-397B has n = 6; per-model tests are exploratory.
- The holdout is a committed participant, not an adversary; whether an adversarial agent could exploit the same dynamic is a hypothesis for future work.
